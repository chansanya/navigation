Navigation

基于 Vue 3 + Cloudflare Pages + D1 构建的个人网址导航站，支持远程 MCP AI 管理

快速上手MCP 接入

无服务器全栈架构

基于 Cloudflare Pages + Pages Functions + D1 (SQLite) 构建，零服务器运维成本即可自托管部署。

远程 MCP AI 管理

内置 Streamable HTTP MCP 服务端点，AI 助手可通过预览确认机制安全地检索、添加与修改导航站点。

隐私空间与密码保险箱

支持隐藏式隐私空间分类与前端 WebCrypto 加密的随身记录，服务端仅存储密文。

深度外观定制

支持毛玻璃与赛博朋克主题、图片/视频/粒子背景，以及顶栏、菜单和卡片的细粒度颜色与透明度配置。

访客投稿与审核

访客可提交推荐站点并自动抓取元数据，管理员审核通过后正式收录并检测重复 URL。

书签与 Cloudflare 同步

支持浏览器书签导入导出，并可从 Cloudflare 账号自动同步 Pages/Workers 项目。
